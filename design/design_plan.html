AI 프롬프트 다듬기 도구

막연한 요청을 명확한 AI 지시문으로 변환하는 웹 도구 — 작동 방식 및 설계 검토

작성일: 2026-10-13 기반 자료: prompt_refinement_guide.md 최종 산출물: output/index.html

⚠ 컨펌 전 결정이 필요한 항목

  • AI 연동 여부 — 실제 AI API를 호출해 자동 변환할지, 아니면 가이드라인 기반 수동 작성 보조 도구로만 만들지
  • 모드 구성 — "빠른 변환(딕셔너리 기반)" 모드와 "전체 템플릿 작성" 모드를 둘 다 제공할지, 하나만 할지
  • 저장 기능 — 작성한 프롬프트를 브라우저 localStorage에 저장(히스토리)할지 여부
  • 언어 — UI 전체를 한국어로만 할지, 영문 병기 여부

원칙 기반

별도 설치 없이 브라우저에서 바로 사용. 서버 없이 순수 HTML/JS로 동작

3. 기능 목록
  • 핵심
    거친 메모 입력 영역 — 자유 텍스트로 원하는 것을 아무렇게나 적는 시작점
  • 핵심
    C-R-O-F-T 구조화 입력 패널 — Context / Role / Objective / Format / Tone 각각 입력칸 + 예시 힌트
  • 핵심
    완성 프롬프트 실시간 미리보기 — 입력할 때마다 조합된 결과를 즉시 표시
  • 핵심
    원클릭 복사 — 완성 프롬프트를 클립보드에 바로 복사
  • 핵심
    모호한 표현 변환 사전 패널 — "이것 좀 잘 써줘" 같은 모호한 표현 예시와 개선 예시 상시 참조
  • 확장
    3단계 워크플로 체크리스트 — 동사 구체화 / 정량화 / Negative Prompt 가이드를 체크하며 진행
  • 확장
    히스토리 저장 — localStorage에 최근 10개 프롬프트 저장·불러오기
  • 추후 고려
    AI 자동 변환 — Claude API를 연결해 거친 메모를 자동으로 C-R-O-F-T 형식으로 변환 제안

6. 컨펌 체크리스트
  • C-R-O-F-T 5대 원칙을 UI 구조의 핵심 축으로 사용 — 가이드 자료와 일치
  • 모호한 표현 변환 사전 테이블을 참조 패널로 상시 노출 — 가이드 자료 §2 활용
  • 완성 프롬프트는 가이드의 "실전 교정 템플릿" 형식을 따라 자동 조합
  • 단일 HTML 파일 — 설치 없이 바로 사용 가능
  • AI API 연동: 우선 미포함으로 제작 후, 추후 Claude API 키 입력란 추가 방식으로 확장 예정 — 이 방향으로 진행해도 되나요?
  • 히스토리(저장) 기능: 포함 / 미포함 중 선택이 필요합니다.
  • 레이아웃: 좌(입력) / 우(결과) 2단 분할 방식 vs 상(입력)→하(결과) 1단 방식 — 어느 쪽이 편하신가요?
