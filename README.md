# AI 프롬프트 다듬기 도구

> 머릿속의 거친 생각을 AI가 즉시 이해할 수 있는 고품질 프롬프트로 변환하는 웹 도구

## 개요

AI와 소통할 때 발생하는 오해를 줄이고 원하는 결과를 더 잘 얻기 위한 **프롬프트 작성 보조 도구**입니다.  
C-R-O-F-T 5대 원칙을 UI에 내재화하여 자연스럽게 학습하면서 사용할 수 있습니다.

## 사용 방법

`output/index.html` 파일을 브라우저에서 열면 바로 사용할 수 있습니다. 설치나 서버 설정이 필요 없습니다.

### 작동 흐름

1. **거친 메모** 입력 — 자유 형식으로 하고 싶은 말을 적습니다
2. **C-R-O-F-T 구조화** — 5가지 항목을 채워 프롬프트를 정교하게 만듭니다
3. **완성 프롬프트 확인** — 실시간으로 조합된 결과를 오른쪽에서 확인합니다
4. **복사** — 원클릭 또는 `Ctrl + Enter`로 클립보드에 복사합니다

## C-R-O-F-T 원칙

| 항목 | 설명 |
|---|---|
| **C** Context | 작업의 배경과 목적 |
| **R** Role | AI에게 부여할 전문가 역할 |
| **O** Objective | 검증 가능하고 구체적인 작업 목표 |
| **F** Format | 결과물의 출력 형태 (표, 목록, JSON 등) |
| **T** Tone | 어조, 분량, 제외 사항 등 제약 조건 |

## 주요 기능

- C-R-O-F-T 5항목 입력 + 각 항목별 예시 힌트
- 완성 프롬프트 실시간 미리보기 및 글자수 표시
- 헤더 완성도 바 (0/5 → 5/5, 빨강 → 초록)
- 포맷 칩 버튼 (번호목록 / 표 / 개조식 / JSON 등)
- 3단계 품질 체크리스트
- 모호한 표현 변환 사전 (5가지 예시)
- localStorage 히스토리 저장 (최대 10개)
- 반응형 레이아웃 (PC: 좌우 2단 / 모바일: 상하 1단)

## 프로젝트 구조

